# Rock-Paper-Scissors-Multiplayer-Game

It's a multiplayer rock-paper-scissors game website where you can play with your friends in online mode or challenge other players. The game is built using Django for the backend, SQLite for the database, and JavaScript for the frontend.

## Features

- **Real-time multiplayer gameplay**: Play with your friends in online mode or challenge random opponents.
- **Easy and intuitive interface**: Simple, clean, and easy-to-use UI.
- **Cross-platform**: Play from any device with a web browser (PC, mobile, tablet).
- **Player statistics**: Keep track of your wins, losses, and overall performance.

## Technology Stack

- **Backend**: Python, Django
- **Database**: SQLite
- **Frontend**: JavaScript, HTML, CSS
- **Deployment**: PythonAnywhere
